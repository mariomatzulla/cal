Link of an event, used with contentAs="content": - private events (shown as "busy"): no link - type 1 (shortcut to page): link to the page - type 2 (link to external url): link to the URL (typolink parameter, e.g. "https://example.org _blank") - otherwise: link to the event view, if it is allowed (eventLink.enabled, see ContentController::getViewLinkConfiguration()) Without link the content is wrapped in a span or div (tag). Cancelled, tentative, busy and private events get the classes cal-event--cancelled / --tentative / --busy / --private and a note (Event/Status).
