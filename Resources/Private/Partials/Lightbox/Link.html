Link to the enlarged image, opened in a lightbox. The markup works with all lightbox scripts of EXT:ns_all_lightbox (Lightbox2, Fancybox, Darkbox, Swipebox, Featherlight) - only the attributes of the active one are used. Without a lightbox script the link simply opens the image. Arguments: image (FileReference), group (images opened together), title, content (thumbnail) {content -> f:format.raw()}
