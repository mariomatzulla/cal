# Security Policy

## Supported versions

| Version | TYPO3 | Supported          |
|---------|-------|--------------------|
| 4.x     | 14    | :white_check_mark: |
| < 4.0   | ≤ 13  | :x:                |

## Reporting a vulnerability

Please do **not** report security issues in public issues, pull requests or forums.

Report them privately instead:

- on GitHub: **Security → Report a vulnerability** of this repository
  (private vulnerability reporting), or
- to the TYPO3 Security Team: security@typo3.org — the team coordinates
  security issues of extensions in the TYPO3 Extension Repository (TER).

Please include the version of cal, TYPO3 and PHP, the affected feature (e.g. the
CalDAV server, the frontend plugin, the backend modules) and the steps to
reproduce the issue.

You will get an answer within a few days. Fixed vulnerabilities are published
as security release in the TER and on GitHub, together with a security advisory.
